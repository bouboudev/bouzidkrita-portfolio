« Leave the code better than you found it. »

Pas de grande refonte à chaque ticket : renommer une variable obscure,
supprimer du code mort, simplifier une condition, extraire une fonction
trop longue, ajouter un test manquant.

Appliqué par toute une équipe, ça change la maintenabilité.
La limite : livrer la fonctionnalité d'abord, améliorer ce qu'on touche —
sans transformer chaque ticket en chantier de refactoring.
