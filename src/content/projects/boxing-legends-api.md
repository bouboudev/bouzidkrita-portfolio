Cette API REST construite avec Node.js et Express propose plusieurs endpoints autour de boxeurs
célèbres, avec une logique métier de scoring permettant de déterminer si un boxeur peut être
considéré comme une légende plutôt qu'un simple CRUD.

Le projet reste volontairement un MVP : les données sont stockées dans un fichier JSON local sans
base de données, l'objectif étant de démontrer la conception d'une API structurée avec une vraie
logique métier plutôt qu'un exercice de style technique complexe.

*Note : le déploiement Render peut être temporairement indisponible après une période
d'inactivité (mise en veille automatique du service gratuit).*
